# 🗄️ MySQL: Banco de Dados e Linguagem SQL

## 📝 Descrição

Este repositório reúne minhas atividades, exercícios e projetos práticos focados na construção, gerenciamento e consulta de bancos de dados relacionais utilizando o **MySQL**.

## 🚀 Conteúdos e Tópicos Abordados

- **Modelagem de Dados:** Criação de diagramas ER (Entidade-Relacionamento), normalização e definição de relacionamentos (1:1, 1:N, N:M).
- **Linguagem SQL Básica e Intermediária:**
  - **DDL (Data Definition Language):** `CREATE`, `ALTER`, `DROP`.
  - **DML (Data Manipulation Language):** `INSERT`, `UPDATE`, `DELETE`.
  - **DQL (Data Query Language):** Consultas com `SELECT`, filtros (`WHERE`, `LIKE`, `IN`, `BETWEEN`) e ordenação (`ORDER BY`).
- **Consultas Avançadas:**
  - Junções de tabelas (`INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`).
  - Funções de agregação (`COUNT`, `SUM`, `AVG`, `MAX`, `MIN`) e agrupamentos (`GROUP BY`, `HAVING`).
  - Subconsultas e visões (`VIEWS`).
- **Integridade e Estrutura:** Aplicação de chaves primárias (`PRIMARY KEY`), chaves estrangeiras (`FOREIGN KEY`) e restrições (`CONSTRAINTS`).
